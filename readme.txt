Динамический пиксель Meta (Facebook/Instagram) с UTM-атрибуцией, реферером,
origin лида, отслеживанием покупки на странице "Спасибо", серверным Conversions API
и встроенной аналитикой прямо в админке WordPress.

== Возможности ==

* Установка Pixel ID и токена Conversions API из админки (Meta Pixel → Настройки).
* Автоматический проброс UTM-меток (first-touch + last-touch), хранение в cookie.
* Запоминание реферера и origin лида: facebook, instagram, google, yandex, vk и т.д.
* Построение _fbc из fbclid для точной атрибуции рекламного клика.
* Advanced Matching: email, phone, first_name, last_name, city, state, zip,
  country, external_id (+ fbp, fbc) — и в пиксель, и на сервер.
* События: PageView, ViewContent, AddToCart, InitiateCheckout, Purchase.
* Purchase на странице "Спасибо": автоматически для WooCommerce
  (хук woocommerce_thankyou) или по ID страницы для лендингов.
* Серверная отправка (CAPI) с дедупликацией по event_id и SHA-256 хэшированием.
* Встроенная аналитика (Meta Pixel → Аналитика): KPI, выручка и средний чек,
  воронка, график по дням, топ origin/UTM-источников, последние события,
  разбивка браузер (Pixel) vs сервер (CAPI). Без обращения к Meta — данные на сайте.
* Исключение команды (редакторы/админы) из статистики и трекинга.
* Авто-очистка старых записей по настраиваемому сроку хранения.

== Установка ==

1. Загрузите ZIP через «Плагины → Добавить новый → Загрузить плагин».
2. Активируйте плагин.
3. Откройте «Настройки → Meta Pixel», впишите Pixel ID (и токен CAPI при необходимости).
4. Сохраните.

== Проверка ==

* Браузерные события — расширение Meta Pixel Helper.
* Серверные события — Events Manager → Test Events (введите Test Event Code в настройках).

== Журнал изменений ==

= 1.1.6 =
* В строке плагина добавлена ссылка «Проверить обновления»: сбрасывает кэш и сразу
  запрашивает GitHub, не дожидаясь плановой проверки WordPress (~12 ч).

= 1.1.5 =
* Аналитика стала валюто-зависимой: «Выручка» и «Средний чек» считаются и показываются
  раздельно по каждой валюте (покупки WooCommerce в £, лиды в $ и т.д.), с символами
  валют. Раньше на всю выручку навешивалась одна валюта из настроек — это исправлено.
* Валюта лидов (лендинговые страницы "Спасибо") по умолчанию — USD.

= 1.1.4 =
* WooCommerce Purchase теперь отправляется только для оплаченных заказов
  (по умолчанию статусы processing и completed) — failed/cancelled/pending/on-hold
  больше не засчитываются. Набор статусов настраивается фильтром mdp_purchase_statuses.
* Отложенная/асинхронная оплата: серверный Purchase (CAPI) уходит по подтверждению
  оплаты (woocommerce_payment_complete / order_status_completed), а не только на «Спасибо».
  Дедупликация по event_id purchase.ORDER_ID сохраняется — дублей нет.

= 1.1.3 =
* Критическое исправление: последовательность «*/» внутри комментария досрочно
  закрывала блок-комментарий и вызывала фатальную ошибку парсинга при активации
  (в 1.1.1 и 1.1.2 плагин не активировался). Теперь всё корректно.
* CI: перед сборкой релиза выполняется php -l по всем файлам, плюс линт на каждый push —
  битый код больше не попадёт в релиз.

= 1.1.2 =
* Релизы теперь собираются автоматически (GitHub Actions): к каждому релизу
  прикладывается готовый zip плагина с корректной структурой каталога.

= 1.1.1 =
* WooCommerce: объявлена совместимость с HPOS (новое хранилище заказов) и блоками
  корзины/оформления — Woo больше не помечает плагин как несовместимый.
* Исправлено: повторный показ страницы «Спасибо» (не WooCommerce) больше не плодит
  дубли Purchase — event_id теперь стабилен на посетителя, серверное событие шлётся один раз.
* Исправлено: рассогласование часовых поясов в аналитике — время событий хранится в UTC,
  график по дням и «последние события» теперь показывают корректные даты/время.
* Безопасность: токен Conversions API больше не выводится в исходный код страницы настроек.
* Conversions API: IP клиента валидируется; статус неблокирующей отправки помечается как «queued».
* Аналитический эндпоинт принимает только известные имена событий.
* Добавлена полная очистка данных при удалении плагина (uninstall.php) и загрузка перевода.

= 1.1.0 =
* Базовый релиз: пиксель, CAPI, UTM-атрибуция, встроенная аналитика.
